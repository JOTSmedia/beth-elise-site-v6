# V6 delivery provenance

No images were generated or redesigned for this performance fix. All original image files, including high-resolution exports and the approved logo, are retained byte-for-byte from v5. Their earlier generation prompts and native/source-resolution reports remain in this package.

239 additional WebP delivery assets are resized copies of those existing files. No crop, recoloring, placement or image-map change is applied. `delivery-provenance-v6.json` records each source export size, delivery size and file size. An export size does not establish native generated detail.

HTML uses responsive image candidates appropriate to the rendered image width. Canvas textures use 512px mobile / 1024px desktop copies; the panoramic texture uses 1024px / 2048px. The mobile hero is 2580×1440 and the mobile footer is 2064×1152, preserving the exact original forest aspect ratio. Full-resolution originals remain available for desktop photographs and direct image access. The visual content, script lettering, color palette, glow rules, fonts and licenses are unchanged.
